# Changelog

All notable changes to this proof of concept are documented here.

## 0.2.0 — 2026-08-10

### Added

- Sparse node discovery descriptors, unlimited search documents, exact named
  embedding spaces, and harness–registry capability negotiation.
- Replayable discovery queries, coverage receipts, closed-world registry
  snapshots, content-addressed node packs, and twelve strict portable schemas.
- Semantic solution templates with visible stages, exact slot partitions, and
  bounded control-plane refinement policies.
- Eighteen cross-domain templates containing 317 atomic obligations plus a
  generated reference node pack with explicit identity, validation, file, and HTTP nodes.
- Strict linear-template blueprints, an eighteenth portable schema, a
  dependency-free `solutiongraph` authoring CLI, a getting-started guide, and
  focused workspace skills for template, node-pack, and benchmark work.
- Seeded random-sprout route proposals around full or partial anchors with
  explicit sampling budgets and accounting.
- Successive-halving resource promotion and deterministic patience-based early stopping.
- Agent patterns, anti-patterns, node/discovery/template/experiment references,
  and protocols for reusable node repositories and template instantiation.
- Domain-neutral `solutiongraph` compiler core, independent of BrowserGraph.
- Strict semantic program, node ABI, candidate registry, admitted space,
  frozen plan, search report, and immutable evidence representations.
- Nominal versioned types with exact schemas, media types, units, and
  cardinalities; conversions require explicit adapter nodes.
- Complete candidate/slot admission with capability, effect, permission, port,
  cardinality, and n-ary route-constraint validation.
- Prior-guided, bounded beam, and explicitly budgeted exhaustive search with
  transparent route-space accounting and content-addressed plan compilation.
- Run receipts, experiment designs, Pareto ranking, and observational belief
  learning kept outside semantic definitions.
- Bundled strict JSON Schemas and a domain-neutral document extraction example.
- Normative universal graph specification and primary-source research notes.
- Cross-harness repository guidance through `AGENTS.md`, `CLAUDE.md`,
  `GEMINI.md`, Copilot instructions, `llms.txt`, and four workspace Agent Skills.

### Changed

- Reframed BrowserGraph as one adapter and stress test of the universal core.
- Expanded CI lint coverage to the universal package and its contract tests.

## 0.1.0 — 2026-08-10

### Added

- Generalized task hierarchy with macro-stage submatrices and atomic substeps.
- Standardized node manifests and versioned workbench JSON Schema.
- Complete candidate discovery and contract-aware route validation.
- Six example macro stages, 21 atomic substeps, 154 node families, and 634
  concrete candidates.
- Five interactive offline projections: hierarchical matrix, exhaustive path
  network, route comparison, step-by-step builder, and feedback control plane.
- Substep, macro-stage, and complete-route optimization decision traces.
- Execution receipts with substep outcomes and macro-stage aggregates.
- Universal architecture blueprint, implementation guide, roadmap,
  contribution guidance, and security policy.

### Preserved

- BrowserGraph's composable multi-engine runtime, contracts, isolation,
  plugins, CLI, server, Docker deployment, notebooks, and tests.
